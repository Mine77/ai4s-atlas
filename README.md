# AI4S Atlas

用 Fumadocs 建立的中文 AI for Science 项目研究网站。首页可按研究主体所在国家或地区、科研环节、进展程度和项目类别组合筛选。

## 开发与部署

使用 Node.js 22.12 或更高版本，在仓库根目录执行 `npm ci` 和 `npm run dev`。运行 `npm run build` 可生成 `out/`，适用于 Cloudflare Pages 或其他静态托管。用 `NEXT_PUBLIC_BASE_PATH` 指定子目录部署前缀，部署到独立域名时留空。

## 更新项目

每份 Markdown 档案位于 `content/project/`。从现有档案复制文件头并填写项目分类、国家、科研环节及进展程度。页面会自动进入首页、目录和搜索索引。

国家可多选，依据是研发或运营主体所在国。科研环节按有证据的能力多选，纯数值预报等其他任务保留空数组。进展程度描述当前可核实的交付状态：研究验证、公开可用、实际部署或临床开发，跨领域项目的标签不代表统一的行业排名。融资信息区分公司募资、科研经费和商业合同。研究记录以署名来源及披露日期为准。
